# Day 2 — Linux Practice

## 1. Commands Used

- `mkdir` — Creates a new folder.
- `cd` — Changes the current folder.
- `nano` — Opens a text editor to create or edit a file.
- `chmod +x` — Gives a file permission to run.
- `./hello.sh` — Runs the script in the current folder.
- `echo` — Prints text on the screen.
- `whoami` — Shows the current username.
- `date` — Shows the current date and time.
- `cp` — Copies a file.
- `mv` — Moves or renames a file.
- `rm` — Removes a file.
- `ls -la` — Shows files, including hidden files, with details.
- `pwd` — Shows the current folder path.
- `cat` — Displays the contents of a file.
- `ssh` — Connects to another computer securely.
- `exit` — Closes the current terminal session.
